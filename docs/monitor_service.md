# Continuous monitor service

M1 supplies checkpointed Falco ingestion, event classification, container event discovery,
exact-ID gate bypass auditing and local status. M2–M4 now connect per-container learning,
ready-model scoring, durable incident creation, Option B confirmation, bounded response,
backtested rule candidates and asynchronous AI explanations.

See [monitor_operations.md](monitor_operations.md) for configuration, privileges, start/stop,
health inspection, tokens, recovery and limitations. See [monitor_evaluation.md](monitor_evaluation.md)
for controlled evaluation; no new live detection or latency measurements are claimed.

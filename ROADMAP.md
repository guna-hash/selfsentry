# SelfSentry delivered scope

SelfSentry combines deployment checks, native runtime monitoring,
per-container anomaly scoring, incident correlation, supervised rule
generation and an auditable response workflow.

The implemented release includes its dashboard, operational tools,
verified journal export and manual baseline-archive tooling.

The delivery scope is closed. No additional milestones are scheduled.
Recorded evaluations and their boundaries are documented in
docs/repository-audit/report.md and docs/known_limitations.md.
